Recommended products widget

One script tag and one element on any page; React + TypeScript inside a web component. Back to the store

Try it

Embed it on your page


        

      


      

        
Attributes

        

          
appliance-idThe product being viewed. Without it: the store's best sellers.

          
limit1 to 12, default 4.

          
langen or uk; default: the page's <html lang>.

          
headingReplaces the default heading.

          
link-target_blank (default) or _self.

          
store-urlOnly if the script is not loaded from the store itself.

        

        

          Styling: --asw-accent, --asw-text, --asw-muted,
          --asw-card-bg, --asw-border, --asw-radius,
          --asw-font, --asw-card-min-width.
          Event: recommendation-select (event.detail is the product).
